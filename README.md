# 日記（スマホ用ビューア）

Google ドライブの「日記」フォルダを読んで表示する PWA です。サーバーは不要で、GitHub Pages などに置くだけで動きます。

## 仕組み

- 日記の本体はドライブの `日記/YYYY-MM-DD.json`。Claude がチャットから書き込みます。
- アプリから書いたメモは `日記/YYYY-MM-DD.memo.<時刻>.json` として保存されます。次に Claude と話すときに本文へまとめ、メモのファイルはゴミ箱へ移します。
- 読み込んだ日記は端末（IndexedDB）に保存され、オフラインでも見られます。

## セットアップ（初回だけ・約30分）

### 1. GitHub Pages に置く
1. 新しいリポジトリ（例：`diary`、公開で可）を作り、このフォルダの中身をすべて置く。
2. Settings → Pages → Branch を `main` / `(root)` にして保存。
3. `https://<ユーザー名>.github.io/diary/` が公開 URL になる。

コードに秘密情報は含まれません（クライアント ID は公開して問題ない値）。日記データはリポジトリに入りません。

### 2. Google Cloud で OAuth クライアントを作る
1. https://console.cloud.google.com/ で新しいプロジェクトを作る。
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効にする。
3. 「OAuth 同意画面」
   - User Type：外部
   - 公開ステータス：**テスト** のままにする
   - テストユーザーに自分の Gmail を追加する
   - スコープに `drive.readonly` と `drive.file` を追加する
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - 種類：ウェブ アプリケーション
   - 承認済みの JavaScript 生成元：`https://<ユーザー名>.github.io`
   - 承認済みのリダイレクト URI：`https://<ユーザー名>.github.io/diary/`（末尾の `/` まで一致させる）
5. 表示されたクライアント ID を `config.js` の `CLIENT_ID` に貼って push する。

### 3. スマホに入れる
- iPhone：Safari で公開 URL を開く → 共有 → 「ホーム画面に追加」
- Android：Chrome で開く → メニュー → 「アプリをインストール」

ホーム画面のアイコンから開き、「Google でログイン」を押す。「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進む（自分で作ったテスト中のアプリなので問題ありません）。

## 補足
- ログインは1時間ごとに切れますが、開いたときに自動で更新されます（Google 側のログインが残っている間は操作不要）。
- 表示がおかしくなったら「記録」タブの「すべて読み込み直す」。
- アプリを更新したら `sw.js` の `CACHE` の値（`diary-shell-v1`）を1つ上げると、端末側も新しい版に切り替わります。
